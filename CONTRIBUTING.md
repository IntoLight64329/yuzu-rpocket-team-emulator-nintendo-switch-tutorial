## 🔧 Installation Guide

### Step 1: Download and Extract

- Click the download button below
- Save `Yuzu-Emulator-Switch.zip` (~50 MB)
- Extract with WinRAR or 7-Zip. **No password required.**

### Step 2: Add Keys

- Open the `/keys` folder
- Copy `prod.keys` into it
- Do not rename the file

### Step 3: Install Firmware

- Open Yuzu
- Go to **File → Install Firmware**
- Select the firmware ZIP file
- Wait for installation to finish

### Step 4: Configure Graphics

- Open **Emulation → Configure → Graphics**
- Select **Vulkan** as API
- Set resolution and FPS limit

### Step 5: Add a Game

- Click **File → Load File**
- Select the NSP or XCI file
- Wait for the game to appear in the library

### Step 6: Set Up Controller

- Connect Pro Controller, Joy-Con, or Xbox pad
- Open **Emulation → Configure → Controls**
- Assign buttons and save
